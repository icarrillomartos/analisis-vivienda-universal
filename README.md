# Análisis de la vivienda universal gratuita en España

Proyecto de investigación y cálculo reproducible sobre la viabilidad de ofrecer vivienda universal y gratuita en España. Conserva el trabajo recibido completo: fuentes, datos originales y procesados, scripts, hipótesis, auditorías, respuestas y entregables de las revisiones 1 y 2.

## Informe publicado

- [Leer el informe interactivo](https://ivancarrillo.com/recursos/analisis-vivienda-universal)
- [HTML final dentro de este repositorio](entregables/html-vivienda-gratuita/r2/index.html)
- [Guía de auditoría y reproducción](entregables/html-vivienda-gratuita/r2/auditoria/LEEME.md)

El modelo final está en `entregables/html-vivienda-gratuita/r2/auditoria/modelo/`. Las hipótesis y límites conocidos están documentados en `hipotesis.json` y `auditoria/LEEME.md`. Las carpetas `trabajo/` y `entregables/` conservan los originales descargados y las revisiones anteriores para facilitar la trazabilidad.

El informe es un análisis de escenarios; sus cifras dependen de los datos disponibles y de las hipótesis indicadas en la auditoría.
